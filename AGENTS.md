# AGENTS.md – Proyecto SetupLab
## Trabajo Final Integrador – Viedma Digital

Este archivo contiene las instrucciones obligatorias para el desarrollo del sitio web SetupLab. Todos los cambios realizados en el proyecto deben respetar estos requisitos.

# 1. Descripción del proyecto

SetupLab es un proyecto de comercio tecnológico especializado en componentes informáticos, periféricos, equipos de PC gaming y servicios técnicos.

Su público objetivo se encuentra principalmente en Viedma y Carmen de Patagones, Argentina.

El objetivo es adaptar la plantilla ZayShop para desarrollar un sitio web profesional, moderno y responsive que represente la identidad de SetupLab.

# 2. Tecnologías obligatorias

- HTML5 semántico.
- CSS3.
- Flexbox y CSS Grid.
- Responsive Design.
- JavaScript ES6+.
- Bootstrap 5, aprovechando la tecnología incluida en la plantilla original.
- Git y GitHub para el control de versiones.
- GitHub Pages para la publicación del sitio web.

No incorporar React, Next.js ni otros frameworks que no sean necesarios para cumplir la consigna.

# 3. Estructura obligatoria: cinco páginas HTML

El sitio web debe estar compuesto por exactamente cinco páginas principales, enlazadas mediante un menú de navegación común utilizando la etiqueta `<nav>`.

Todas las páginas deben mantener una navegación coherente y permitir acceder a las demás secciones.

## 3.1. HOME – index.html

Debe incluir:

**Hero Section**
- Imagen o carrusel de presentación.
- Título de impacto relacionado con SetupLab.
- Llamado a la acción (CTA).

**Tres tiras o franjas resumidas:**

1. Resumen de los servicios prestados.
2. Resumen de trabajos o clientes destacados.
3. Resumen institucional con una presentación de la empresa y acceso a la sección correspondiente.

## 3.2. EQUIPO – equipo.html

Debe incluir:

**Descripción de la empresa:**
- Misión.
- Visión.
- Valores.

**Integrantes del equipo:**

Tarjetas (cards) con las fichas de un mínimo de tres integrantes. Cada tarjeta debe incluir:
- Fotografía.
- Nombre.
- Rol o función.
- Enlaces a redes sociales.

## 3.3. SERVICIOS – servicios.html

Debe incluir el detalle completo de las prestaciones ofrecidas por SetupLab.

Se deben presentar como mínimo tres servicios, maquetados utilizando Flexbox y/o CSS Grid.

Los servicios pueden incluir:
- Armado personalizado de PC.
- Mantenimiento y reparación.
- Actualización de componentes y asesoramiento técnico.

## 3.4. TRABAJOS / CLIENTES – trabajos.html

Debe incluir una galería o catálogo visual de los principales proyectos, trabajos o clientes.

Requisitos:
- Mínimo cinco trabajos o clientes.
- Presentación visual organizada.
- Utilización obligatoria de CSS Grid para estructurar la galería o catálogo.

## 3.5. CONTACTO – contacto.html

Debe incluir:

**Datos directos de contacto:**
- Teléfono.
- Correo electrónico.
- Dirección física.
- Mapa de ubicación.

**Redes sociales:**
- Enlaces a los perfiles correspondientes.

**Formulario de contacto accesible:**

Debe contener obligatoriamente los siguientes campos:
- Nombre.
- Email.
- Asunto.
- Mensaje.

# 4. Identidad visual de SetupLab

El diseño debe transmitir una imagen tecnológica, moderna y profesional, incorporando detalles visuales relacionados con el mundo gaming.

**Estilo visual:**
- Profesional con detalles gamer sutiles.
- Diseño limpio, ordenado y moderno.
- Buena legibilidad y jerarquía visual.
- Evitar diseños excesivamente recargados o futuristas.

**Paleta de colores:**
- Azul oscuro como color principal.
- Blanco como color de contraste.
- Celeste eléctrico como color de acento.

# 5. Adaptación de la plantilla ZayShop

Se debe utilizar la plantilla ZayShop descargada como base del proyecto.

Indicaciones:
- Aprovechar los componentes, estilos y recursos existentes.
- Adaptar la estructura original a las cinco páginas obligatorias.
- Renombrar y reorganizar las páginas cuando sea necesario.
- Mantener los recursos útiles de la carpeta assets.
- Adaptar textos, imágenes, productos y elementos visuales a SetupLab.
- Eliminar contenidos de demostración que no correspondan al proyecto.
- Evitar duplicar páginas o crear secciones principales innecesarias.
- Mantener el código ordenado, legible y fácil de comprender.

La estructura original de ZayShop no debe limitar el cumplimiento de la consigna académica.

# 6. Requisitos técnicos y de calidad

Todos los requisitos siguientes son obligatorios:

- Utilizar HTML5 semántico.
- Aplicar CSS3.
- Implementar diseño responsive para computadoras, tablets y celulares.
- Utilizar JavaScript ES6+.
- Incorporar Flexbox y CSS Grid donde corresponda.
- Mantener un menú de navegación común en las cinco páginas.
- Comprobar que los enlaces y las funcionalidades funcionen correctamente.
- Garantizar que las imágenes y los recursos carguen correctamente.
- Mantener una estructura de archivos clara y organizada.

# 7. Control de versiones y despliegue

El proyecto debe contar con:

- Un repositorio público en GitHub.
- Un archivo README.md documentado.
- Publicación del sitio web en vivo mediante GitHub Pages.

# 8. Indicaciones para el desarrollo con OpenCode

- Antes de modificar archivos, analizar la estructura completa de la plantilla.
- No sobrescribir ni eliminar archivos sin comprobar previamente su utilidad.
- Trabajar por etapas y explicar brevemente los cambios realizados.
- No modificar los requisitos obligatorios de la consigna.
- No inventar información comercial real. Cuando falten datos, utilizar contenido de ejemplo claramente identificable.
- Priorizar un código comprensible para un estudiante de Desarrollo Web.
- No considerar terminado el proyecto hasta verificar el cumplimiento de los cinco apartados y todos los requisitos técnicos.

# 9. Prioridad de los requisitos

La consigna académica de Viedma Digital tiene prioridad sobre las decisiones estéticas o las funcionalidades originales de ZayShop.

El resultado final debe ser un sitio web de cinco páginas que represente a SetupLab y cumpla todos los requisitos establecidos en este documento.
