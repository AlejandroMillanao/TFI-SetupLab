# SetupLab

## Sobre el proyecto

SetupLab es un emprendimiento ficticio dedicado al mundo de la informática y el gaming. Se presenta como una propuesta de comercio tecnológico orientada a la venta de componentes de PC, periféricos y equipos, además de ofrecer servicios de armado personalizado, mantenimiento, reparación y actualización de computadoras.

Está pensado para usuarios de Viedma y Carmen de Patagones que buscan productos tecnológicos, asesoramiento y soluciones para sus equipos, tanto para uso cotidiano como para gaming.

## Tecnologías utilizadas

Para el desarrollo del sitio web se utilizaron:

- **HTML5:** para la estructura y organización del contenido.
- **CSS3:** para los estilos, el diseño visual y la adaptación a diferentes dispositivos.
- **Bootstrap 5:** para facilitar la maquetación y el diseño responsive.
- **JavaScript ES6+:** para incorporar funcionalidades e interactividad.
- **Flexbox y CSS Grid:** para organizar los distintos elementos y secciones.

## Páginas del sitio

El sitio está compuesto por cinco páginas principales:

- **Inicio (`index.html`):** presentación de SetupLab, sus principales servicios y trabajos destacados.
- **Equipo (`equipo.html`):** descripción del emprendimiento, su misión, visión y valores.
- **Servicios (`servicios.html`):** presentación de los servicios de armado de PC, mantenimiento, reparación y actualización de equipos.
- **Trabajos (`trabajos.html`):** galería de imágenes con ejemplos de trabajos y soluciones informáticas.
- **Contacto (`contacto.html`):** información de contacto y formulario para consultas.
